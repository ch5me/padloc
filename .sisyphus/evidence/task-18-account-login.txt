=== Root Cause of Prior Failure ===
The SRP protocol was failing because auth.getAuthKey(password) derived a key with its own default PBKDF2 params (1e6 iterations, random salt), while the account key used account.keyParams (1000 iterations, different random salt). These are completely independent derivations — the server stored auth.keyParams on signup, returned them on login, but the client used them consistently because both were derived from the same PBKDF2Params. However, the initial fix auth.keyParams = account.keyParams ensures the keyParams stored by the server match what the account was initialized with, creating a consistent chain from signup through login.
