## Lock Acquisition Rule

- All identities [account.id, ...account.orgs.map(o => o.id)] sorted lexicographically
- Locks acquired in sorted order, preventing deadlock on overlapping identity sets
- Single AccountLockDO class, one instance per identity key

## KV Guardrail

- KV forbidden as authoritative consistency owner
- KV permitted only for: rate-limit hints, ephemeral cache, session presence hints
- All auth/session/vault/org/account state: D1 is sole SSOT
