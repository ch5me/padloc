## Schema Design Decisions

- Blob-shaped: each Storable's full serialized form in a single `data` TEXT column
- Encrypted-at-rest: no plaintext that the Postgres backend encrypts
- ULID-style TEXT PRIMARY KEY for all domain tables
- Composite PK (org_id, account_id) for org_members
- `PRAGMA defer_foreign_keys=on` at migration head (D1 constraint: no `PRAGMA foreign_keys=OFF`)
- 10 MB row size limit documented in schema — vault blobs >10 MB spill to R2
- SQLite LIKE fallback for regex/negex queries (complex patterns throw NOT_IMPLEMENTED)
